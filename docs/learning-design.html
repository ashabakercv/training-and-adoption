Learning design

Personal demonstration / Fictional scenario

Audience and need

Implementation coordinators who understand their project but need a consistent way to communicate status. The learner should be able to distinguish an activity update from an update that supports a decision.

Observable objective

Given source notes, select a status update that preserves the blocker and names the next action, owner and due date when supplied.

Sequence

Explain the five fields, compare a weak and a useful example, then apply the pattern in three short checks. Provide feedback about the specific missing element. Allow retries and keep the job aid available throughout.

Accessibility approach

Use semantic headings, labeled controls, keyboard interaction, visible focus and text feedback. Convey status in words as well as color. Avoid time limits and motion-dependent content. Browser checks cover the implemented example, not a formal WCAG conformance certification.
